## Motivation

ADAS functions mix discrete mode switches with continuous dynamics. Road tests alone are costly and incomplete.

## Approach

- Hybrid automaton reachability for longitudinal ADAS safety (**IEEE SMC 2024**).
- Interpretable control combining hybrid automata with deep RL (**CAC 2024**).
- Enhanced safety–security verification framework (**RESS 2026**).

## Outcomes

A verification and control stack that emphasizes formal guarantees, interpretability, and practical inference cost.
